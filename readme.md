# 📖 Gen AI Storybook

An AI-powered **storybook generator** that creates unique and engaging stories from just **3 words**.  
This project uses **Node.js, Express.js, and Ollama** to generate stories locally without depending on external APIs.

---

## 🚀 Features
- ✨ Enter **any 3 words** → get a full AI-generated story.
- 🎨 Each story is unique, even with the same words.
- ⚡ Powered by **Ollama** (runs LLMs locally).
- 🌍 Fun, interactive, and privacy-friendly..

---

## 🛠️ Tech Stack
- **Backend:** Node.js + Express.js  
- **AI Engine:** Ollama (LLM running locally)  
- **Frontend (optional):** Basic HTML/JS or API client  

---

## ⚡ How It Works
1. User provides **3 random words** (e.g., `dragon`, `moonlight`, `friendship`).
2. The backend sends the words as a prompt to **Ollama**.
3. Ollama generates a creative story based on the words....
4. The story is returned as an API response (or rendered in a frontend).,,
